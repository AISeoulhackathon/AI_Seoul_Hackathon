# IDEA_09: AI 정기 안부 대화와 돌봄 모니터링

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

정해진 시간에 AI가 먼저 말을 걸어 자연스럽게 안부를 묻고 필요한 복지 정보·일정을 알려 주며, 일정 횟수 이상 응답이 없거나 위험 신호가 보이면 담당자에게 알린다.

## 문제

- 담당자 한 명이 많은 대상자를 맡아 직접 찾아가기 어렵다 (회의 중 '1명당 최대 1,000명' 언급 — 확인 필요). 고독사 위험군을 놓친다.
- 근거: 복지 트랙 돌봄 수요·사각지대([brief.md](../hackathon/brief.md)).

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 홀몸어르신 | 낮음 | 담당자 방문·전화 |
| 복지 담당자 | 중간 | 수작업 관리 |

## 해결 방식

- AI가 하는 일: 정기 음성 대화, 대화 기반 심리 상태 분석, 최신 복지 정보 안내, 무응답·위험 감지
- 사람이 하는 일: 담당자 — 알림 받고 방문·연락

## 문턱 낮은 인터페이스

| 체크 | 항목 | 근거 |
| --- | --- | --- |
| [ ] | 앱 설치·회원가입 없이 첫 사용 가능 | 앱 설치 필요 여부 미정 (전화면 불필요) |
| [ ] | 말(음성)·전화·문자처럼 이미 익숙한 채널로 사용 가능 | 음성 대화 |
| [ ] | 글을 잘 못 읽거나 화면이 작아도 쓸 수 있음 (큰 글씨·쉬운 말·스크린리더) |  |
| [ ] | 핵심 결과까지 3단계 이내 | 말만 하면 됨 |
| [ ] | 막혔을 때 사람(창구·배움터·가족)에게 이어짐 | 담당자 알림 |

## MVP 범위

- 데모에서 보여줄 핵심 흐름 1개: AI 안부 대화(앱 내 음성) + 무응답 시 담당자 화면 알림
- 하지 않는 것: 실제 전화망 발신
