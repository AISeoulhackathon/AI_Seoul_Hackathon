# IDEA_08: 음성 복지 상담·신청 도우미

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

전화하듯 말로 대화하면 AI가 맞는 복지 제도를 맨투맨으로 안내하고, 부족한 정보를 되물어 가며 신청까지 돕는 '돌봄 PT'.

## 문제

- 복지 사각지대는 정보를 모르는 것과 신청이 어려운 것 둘 다에서 생긴다. 장애인·고령자는 사이트에서 타자로 신청하기 어렵다.
- 근거: 복지 트랙([brief.md](../hackathon/brief.md)), 회의 중 복지센터 사각지대 발굴 경험담.

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 시각·지체 장애인 | 낮음 | 복지센터 방문·대리 |
| 고령자 | 낮음 | 복지센터 |

## 해결 방식

- AI가 하는 일: 실시간 음성 대화(끼어들기 가능), 제도 안내, 신청 대행(필요 정보 질문)
- 사람이 하는 일: 복지센터 담당자 최종 확인
