# IDEA_03: 마라톤 교통주의보

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

서울 곳곳의 마라톤 경로와 통제 시간을 지도에 표시하고, 언제부터 언제까지 막히는지·어디로 돌아가면 되는지 미리 알려 준다.

## 문제

- 주말 마라톤 교통 통제로 시민이 예고 없이 길이 막혀 돌아가는 불편을 겪는다 (회의 중 당일 온라인 불만 글 사례 언급).
- 근거: 자유 트랙 예시 '교통'([brief.md](../hackathon/brief.md)). 서울 마라톤 개최 빈도·통제 규모는 확인 필요.

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 보행자·자전거 이용자 | 다양 | 지도 앱(차량 경로는 일부 반영) / 현장에서 확인 |
| 통제 구간 주민 | 다양 | 안내 현수막·문자 (확인 필요) |

## 해결 방식

- AI가 하는 일: 흩어진 대회 공지에서 경로·통제 시간을 추출해 구 단위로 정리, 사용자 위치·이동 계획에 맞춰 우회 안내
- 사람이 하는 일: 회의 미논의

## 문턱 낮은 인터페이스

| 체크 | 항목 | 근거 |
| --- | --- | --- |
| [ ] | 앱 설치·회원가입 없이 첫 사용 가능 |  |
| [ ] | 말(음성)·전화·문자처럼 이미 익숙한 채널로 사용 가능 |  |
| [ ] | 글을 잘 못 읽거나 화면이 작아도 쓸 수 있음 (큰 글씨·쉬운 말·스크린리더) |  |
| [ ] | 핵심 결과까지 3단계 이내 |  |
| [ ] | 막혔을 때 사람(창구·배움터·가족)에게 이어짐 |  |

## 시민 체감 시나리오

|  | Before | After |
| --- | --- | --- |
| 상황 | 모르고 나갔다가 길이 막힘 | 미리 알림·우회로 안내 |
| 걸리는 시간·단계 | 회의 미논의 | 회의 미논의 |
| 결과 | 돌아가거나 대기 | 통제 피해서 이동 |

## MVP 범위

- 데모에서 보여줄 핵심 흐름 1개: 다가오는 대회 1개의 경로·통제 시간을 지도에 표시하고 알림·우회 안내
- 하지 않는 것: 전체 행사(축제·집회) 확장

## 데이터·API

| 데이터 | 출처 | 공개 여부 | 확인 상태 |
| --- | --- | --- | --- |
| 마라톤 대회 경로·통제 시간 | 대회 공지·서울시 교통 통제 공지 (확인 필요) | — | 미확인 |
| 지도·경로 API | 확인 필요 | — | 미확인 |

## 서울시 시정·디지털배움터 연계

- 연계 대상 (부서·기관·현장): 서울시 교통 통제 안내와 연계 가능성 (확인 필요)
- MVP 이후 운영 주체·방식: 회의 미논의
