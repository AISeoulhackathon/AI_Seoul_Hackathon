# IDEA_06: 소상공인 AI 홍보물·쇼츠 제작

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

사진만 찍고 채팅하듯 버튼을 누르면 AI가 메뉴 홍보 전단·SNS 이미지·쇼츠 영상을 만들어 준다. 트렌드·밈 반영까지 확장 가능.

## 문제

- 고령 소상공인은 SNS 마케팅·홍보물 제작을 하지 못한다.
- 근거: 소상공인 트랙 '사업부진 50.4%, 사전 위험 대응 부재'([brief.md](../hackathon/brief.md)). 홍보 부족과 폐업의 인과는 근거 없음 — 회의에서 반론.

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 고령 소상공인 | 낮음 | 홍보 안 함 / 자녀 도움 |

## 해결 방식

- AI가 하는 일: 사진 → 홍보 이미지·쇼츠 생성, 트렌드 반영 문구
- 사람이 하는 일: 회의 미논의

## 문턱 낮은 인터페이스

| 체크 | 항목 | 근거 |

| 결과 | 회의 미논의 | 회의 미논의 |

## MVP 범위

- 데모에서 보여줄 핵심 흐름 1개: 가게 사진 → 홍보 이미지 + 짧은 영상
- 하지 않는 것: 실시간 트렌드·밈 분석
