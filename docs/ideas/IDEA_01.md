# IDEA_01: 숨은 전통시장 먹거리 로드맵과 방문 챌린지

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

덜 알려진 서울 전통시장의 가게·메뉴·가격을 AI가 수집·정형화해 먹거리 로드맵을 만들고, 방문 단계를 달성하면 포인트를 주는 챌린지로 발길을 유도한다.

## 문제

- 망원·광장시장처럼 유명한 곳 외의 숨은 시장은 정보가 흩어져 있어 방문객이 찾지 않는다.
- 근거: 자유 트랙 예시 '지역 상권'([brief.md](../hackathon/brief.md)). 숨은 시장의 방문객 감소 통계는 확인 필요.

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 외국인·지방 관광객 | 높음~중간 | SNS 쇼츠·블로그 검색 |
| 시장 상인 | 낮음~중간 | 회의 미논의 |

## 해결 방식

- AI가 하는 일: 웹 리서치로 시장별 가게·메뉴·가격을 수집해 정해진 형식으로 정형화(정기 배치로 갱신), 사용자 취향에 맞는 로드맵 생성
- 사람이 하는 일: 포인트 지급 기준·제휴(온누리상품권 등) 운영

## 시민 체감 시나리오

|  | Before | After |
| --- | --- | --- |
| 상황 | 숨은 시장을 알 방법이 없음 | 로드맵 추천 |
| 걸리는 시간·단계 | 직접 검색·조사 | 회의 미논의 |
| 결과 | 유명 시장만 방문 | 숨은 시장 방문 + 포인트 |

## MVP 범위

- 데모에서 보여줄 핵심 흐름 1개: 시장 2곳을 정해 가게·메뉴 데이터 수집 → 로드맵 생성 → 5곳 방문 시 포인트
- 하지 않는 것: 전체 시장 확장, 실제 상품권 지급

- 연계 대상 (부서·기관·현장): 온누리상품권·전통시장 지원 사업과 포인트 연계 가능성 (확인 필요)
- MVP 이후 운영 주체·방식: 회의 미논의
