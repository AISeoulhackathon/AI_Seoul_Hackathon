# IDEA_12: 서울 한장도우미 — 안내문 한 장을 오늘 할 일로

> 출처: 팀원 개인 기획 초안(2026-11-02, 원본 번호 IDEA_02 → 저장소 번호 IDEA_12). 사용자 인터뷰·구현·실증은 아직 없다. 체크박스는 구현·검증 완료 여부이므로 모두 미체크이고, 시나리오의 단계 수는 설계 목표다. 아래 외부 출처는 원 작성자가 수집한 링크로 이 저장소에서 재확인하지 않았으며 `RES_XX` 조사 카드로 아직 옮기지 않았다(`/research` 대상).

## 한 줄 요약

행정 안내문을 이해하기 어려운 시민이 사진을 올리면 AI가 쉬운 설명·기한·준비물·문의할 내용을 원문 근거와 함께 보여준다.

## 문제

- 안내문을 받은 시민이 행정 용어와 복잡한 조건 때문에 무엇을 언제까지 해야 하는지 파악하기 어렵다 (문제 가설, 인터뷰로 검증 필요). 서울 시민의 동일 문제 규모는 확인하지 않았다.
- 근거: 정보 약자가 제도를 몰라 혜택을 놓치는 정보 격차([brief.md](../hackathon/brief.md) 트랙 ①). 안내문을 받고도 절차를 못 밟는 경우는 이 격차의 뒷단에 해당한다 (추론).
- 선례: [뉴저지 주정부 행정 AI 번역](https://www.nj.gov/labor/lwdhome/press/2024/20241205_aitransition.shtml) — 행정 전문용어·언어 접근성 문제에 용어집·정책 검토·이용자 검증을 적용. 번역 업무 개선은 확인됐으나 사진 인식·행동 안내의 효과는 본 프로젝트에서 검증해야 한다.
- 선례: [GetCalFresh(Code for America)](https://codeforamerica.org/news/california-launches-code-for-americas-getcalfresh-in-all-58-counties/) — 질문·절차 개선으로 초기 신청 시간을 45분에서 10분으로 줄였다는 운영기관 발표. [2025년 운영 종료](https://codeforamerica.org/impact/2025/).

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 고령자·작은 글씨가 어려운 시민 | 개인차 큼; 확대·읽어주기 필요 가능 | 가족·창구에 설명 요청 (가설) |
| 한국어가 익숙하지 않은 시민 | 기기 사용은 가능해도 행정어 이해 어려움 가능 | 번역 도구·지인 도움 (가설) |
| 가족·보호자 | 사진 공유와 메시지 사용 가능 | 안내문을 대신 읽고 준비사항 정리 (가설) |

## 해결 방식

- AI가 하는 일: 사진의 텍스트와 항목 추출, 쉬운 표현 변환, 기한·준비물·문의처 구조화, 결과별 원문 연결. 문서에 없는 조건은 추측하지 않고 확인 질문 생성.
- 사람이 하는 일 (담당자·가족·배움터 강사 등): 시민이 추출된 핵심 항목을 확인한다. 정책·언어 검토자가 용어집과 예시 정답을 검수한다. 담당자가 모호한 서류 요건을 설명한다.

## 시민 체감 시나리오

| | Before | After |
| --- | --- | --- |
| 상황 | 보완 안내문을 받았지만 제출기한과 준비서류를 이해하기 어렵다. | 사진에서 기한·준비물·문의 질문을 추출하고 원문과 대조한다. |
| 걸리는 시간·단계 | 읽기·가족 문의·재확인 반복; 시간 미측정 | 3단계 목표; 촬영 실패·재촬영 단계는 별도 기록 |
| 결과 | 무엇을 해야 할지 불확실함 (가설) | 확인된 행동 목록과 담당자에게 물어볼 사항을 구분 |

## MVP 범위

- 데모에서 보여줄 핵심 흐름 1개: 선명한 인쇄 안내문 한 장 업로드 → 추출 내용 확인 → 기한·준비물·문의처 카드와 원문 강조 표시.
- 하지 않는 것: 모든 필체·저화질 문서 지원, 법적 효력 판정, 문서에 없는 서류 추정, 자동 제출. 외국어·음성은 여력에 따른 확장.
- 범위 전제: 6시간 당일 개발에 맞춘 제안이다. 사전 코드·데이터 준비 허용 범위는 미확인([work-plan.md](../planning/work-plan.md) 미결정).
- 검증 지표(제안): 기한·준비물 이해 정답률, 중요 조건 누락 수.

## 서울시 시정·디지털배움터 연계

- 연계 대상 (부서·기관·현장): 동주민센터 안내 창구, 서울 AI 디지털배움터의 스마트폰·행정문서 활용 교육 (협의 전 제안)
- MVP 이후 운영 주체·방식: 문서 유형별 용어집과 평가 예시를 운영팀이 관리하고, 현장 강사·담당자가 오류를 피드백하는 구조를 제안한다. 공식 운영 주체는 미정.
