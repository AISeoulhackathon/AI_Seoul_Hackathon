# IDEA_05: 비슷한 고민을 가진 사람 익명 매칭

> 출처: [1차 회의](../note/20261102-ideation-meeting-1.md)

## 한 줄 요약

AI에게 고민과 심리 상태를 말하면 비슷한 고민을 가진 사람이나 상담자와 익명으로 이어 주고, 음성 변조로 부담 없이 대화하게 한다.

## 문제

- 소극적이고 위축된 사람은 대화 상대를 찾거나 도움을 청하기 어렵다.
- 근거: 복지 트랙 '정보 약자·사각지대'([brief.md](../hackathon/brief.md)). 은둔 청년 규모는 확인 필요.

## 대상 사용자

| 사용자 | 디지털 역량 | 지금은 어떻게 해결하나 |
| --- | --- | --- |
| 은둔·우울 경향 청년 | 높음 | 회의 미논의 |
| 홀몸어르신 | 낮음 | 회의 미논의 |

## 해결 방식

- AI가 하는 일: 고민 내용으로 비슷한 사람·상담자 매칭, 음성 변조
- 사람이 하는 일: 상담자
