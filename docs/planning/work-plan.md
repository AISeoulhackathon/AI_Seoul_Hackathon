## 이번 반영 사항

- 사용자 제공 [공고·FAQ](../hackathon/announcement-faq.md)를 문서화하고 브리프·상위 정책·평가 기준·MVP 템플릿에 반영했다. 웹 원문을 독립 확인한 것은 아니다.
- IDEA_03을 사용자 요청에 따라 구체화했다. 대상은 운전자와 보행자이며, 자동차/도보 모드별 통제 정보 구분을 제안했다. 후보 `draft` 유지, 팀 선정·MVP 승인은 하지 않았다.
- 준비 경계: 기획·설계·환경·빈 템플릿만 사전 준비, 핵심 기능 코딩은 본선 현장. MVP 승인 여부와 별도로 적용한다.
- 제출 준비: 작동 프로토타입, 기획·기대효과서 PDF, GitHub, 정보 약자 접근성 시연 발표자료.

## 마라톤 자동화 방향 채택

사용자가 [공지 1건 → AI 추출·근거 표시 → 사람 수정·승인 → 지도 반영](../decisions/20261102-marathon-ai-workflow.md)을 채택했다. 자동차·도보 각각의 주변 보기와 목적지 경로 영향 확인은 유지한다. 자동 검색·수집, 변경 감지, 자동 우회는 후속 확장으로 둔다. 팀 최종 선정·MVP 승인과는 별개이며 IDEA_03은 draft다.
