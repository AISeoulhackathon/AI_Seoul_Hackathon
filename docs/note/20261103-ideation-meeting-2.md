## 합의한 것

- **결정은 카톡 익명 투표로.** 강규민이 투표를 올린다. 마감은 11-04(수) 오전. 문서를 다시 보고 한 사람당 2~3개, 중복 투표 가능(이소영·김성진 제안).
- **1등과 2등을 함께 남긴다.** 1등이 기술적으로 어려우면 2등으로 간다. 기술 가능성은 투표 뒤 따로 검토한다.
- **조장 없음.** 수평적으로, 챙길 수 있는 사람이 챙기고 각자 리딩할 수 있는 부분을 리딩한다(강규민 제안, 동의).
- **역할은 주제가 정해진 뒤 다시 본다.** 기획은 6명 모두 함께 한다. 신청서의 팀 역할 칸은 지금 기준 프론트 3·백엔드 3이며(한호수), 각자 가능한 역할을 적어 취합한다. 같은 역할이 겹쳐도 된다.
- **디스코드 채널 알림:** 스레드 알림은 끄고 멘션일 때만 받는다. 회의록은 하네스(이 저장소)에 올리고, 궁금한 것은 챗봇에 물어보면 된다.

## 논의만 하고 정하지 않은 것

### 의사결정 방식

- 한호수: 아이디어가 뽑히면 아이디어를 낸 사람이 의사결정자가 돼야 한다. 같이 기획하더라도 결정할 사람이 없으면 산으로 간다.
- 이소영: 주제가 정해지면 필요한 역할과 포지션이 달라질 수 있으니 주제부터 정하자.
- → 결론 없이 넘어감. 주제가 정해진 뒤 다시 논의.

### 디자인

- 디자이너는 없다. 기획과 UI·UX 설계를 함께 하며 디자인도 같이 챙긴다(강규민).
- 원석규가 디자인 툴을 써야 하는지 물었고, 강규민이 남는 Figma 프로 플랜 계정 1개를 제공하기로 했다. 요즘은 프롬프트로 Figma 디자인이 가능하다는 의견.

### LLM·비용

- API 과금이 생기는데 해커톤 때문에 크레딧을 충전하는 게 맞는지 고민(강규민).
- 한호수가 쓸 수 있는 GPT API 크레딧 약 75달러가 있다. 아껴 쓰면 2~3주 개발에 버틸 수 있을지 모르겠다는 의견.
- 강규민이 회사 GPU 서버에 깔린 오픈 모델("Qn 3.8"로 받아쓰기됨 — 모델명 확인 필요)을 테스트용 API로 쓸 수 있는지 부탁해 보기로 했다. 성능이 GPT 상위 모델 수준이라는 발언이 있었으나 **검증 전**이다.
- 김성진 제안: 테스트는 회사 서버 모델로 완성하고, 한호수의 GPT API로 결과물을 비교해 본선에 쓸 것을 결정하자 → 다들 동의. 강규민: 본선에서는 GPT API를 권하지만, 추론 정확도를 직접 테스트해 보고 정한다.

### 일정 확인

- 사전 세미나는 **11-14(토)**다. 회의 중 8일로 잘못 말한 것을 한호수·강규민이 바로잡았다. 비개발자를 위한 바이브코딩·배포 강의로 보이며 필참 여부는 강규민이 확인한다.
