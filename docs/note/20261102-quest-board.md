## ⑦ 서울 퀘스트 보드 (트랙 ③ + ②)

- 컨셉: 기업과 소상공인의 실제 과업을 청년이 푸는 퀘스트 시스템
- 작동: 기업·스타트업·소상공인·공공기관의 실무 과제를 1~2주 단위 유료 퀘스트로 분할(가게 SNS 운영, 메뉴판 리디자인, 데이터 정리, 간단한 웹페이지). 청년이 수행하면 결과물이 검증된 경험치와 포트폴리오로 누적. 일정 레벨 도달 시 채용 연계. 소상공인 퀘스트 비용은 시가 일부 지원
- 창의 포인트: 청년 미스매칭과 소상공인 역량 부족을 하나의 구조로 동시 해결. '쉬었음' 청년의 첫 경력 진입 장벽 제거
