# 추가 사회문제 아이디에이션

> 기록일: 2026-11-03. 출처: 이번 사용자·에이전트 대화. 아래는 에이전트가 제안한 조사 전 문제 가설이며 사용자가 개별 아이디어를 선정한 것은 아니다. 통계·기존 서비스 차별성·데이터 확보 가능성은 미검증이다.

## 청년 일자리 후보

| 제안 | 문제 가설 | AI 역할 | 데모 흐름 후보 |
| --- | --- | --- | --- |
| 채용공고 번역기 | 직무 용어만으로 실제 업무를 이해하기 어려움 | 공고를 쉬운 말로 설명하고 필수·우대·불명확 조건 구분 | 공고 입력 → 업무 설명 → 지원 전 질문 |
| 경험에서 직무 찾기 | 아르바이트·동아리 경험을 역량으로 설명하기 어려움 | 실제 경험을 되물어 구체화하고 역량·직무 연결 근거 제시 | 경험 입력 → 본인 확인·수정 → 역량·직무 후보 |
| 지원 전 직무 체험 | 직무에 대한 기대와 실제 업무가 어긋날 가능성 | 가상 과제와 수행 과정 피드백 | 직무 선택 → 짧은 과제 → 성향 돌아보기 |

사용자는 취업 외 사회문제도 보자고 요청했다. 위 후보 채택·제외 결정은 없으며 채용 가능성을 단정하지 않는다.

## 후속 검토

- 공공 안내문 후보는 제도를 찾아주는 [IDEA_07](../ideas/IDEA_07.md)과 달리 이미 받은 문서를 이해하고 행동하는 흐름에 집중하는 안이다. 기존 복지 후보와의 겹침 검토가 필요하다.
- 원문에 없는 자격·기한·가용 서비스를 추측하지 않는다. 개인·민감정보 입력을 최소화한다.
- 기존 카드와 중복 비교, 문제·데이터 조사 후 개별 IDEA 카드 승격 여부를 결정한다. 이 메모는 카드 수·점수에 포함하지 않는다.
- 핵심 기능 구현은 대회 당일로 제한하며 현재는 기획만 기록한다.
