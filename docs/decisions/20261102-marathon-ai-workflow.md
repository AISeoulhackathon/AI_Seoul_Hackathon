# 마라톤 후보의 AI 자동화 방향 채택

| 필드 | 값 |
| --- | --- |
| 날짜 | 2026-11-02 |
| 결정자 | 사용자 (대화에서 제안에 “그렇게가자”로 동의) |
| 관련 | IDEA_03 |

## 결정

대회 공식 공지 한 건을 입력하면 AI가 통제 정보를 추출하고, 사람이 원문과 대조해 승인한 뒤 지도에 반영하는 흐름을 채택한다. 운전자·보행자를 대상으로 주변 통제 보기와 목적지 경로 영향 확인을 모두 제공하는 기존 방향을 유지한다.

## 배경

6시간 현장 구현을 고려해 AI의 역할을 공지의 구조화와 쉬운 말 설명에 집중한다. 실제 데이터·API 확보와 구현 가능성은 아직 검증 전이다.

## 역할과 처리 흐름

1. 운영자가 공식 공지 한 건과 출처를 입력한다. 입력 형식은 자료 조사 후 결정한다.
2. AI가 대회명·날짜·경기 시간·도로/구간·통제 시간·대상 이동수단을 추출한다. 각 항목에 원문 근거를 연결하고 누락·상충 항목을 표시한다.
3. 운영자는 추출값과 원문 근거를 나란히 보며 수정·승인한다. 지도 구간도 검수하며, 미승인 추출값은 확정 통제로 게시하지 않는다.
4. 승인된 정보를 주변 지도와 목적지 경로 영향 화면에서 공유한다. 출처·마지막 확인 시각을 표시한다.
5. 경로와 통제 구간의 겹침은 좌표·시간 계산으로 판단하고, AI는 그 결과를 쉬운 말로 설명한다. AI가 경로 또는 통행 가능 여부를 만들어내지 않는다.

차량 통제만 확인되면 보행 통제는 미확인으로 유지한다. 경기 시간과 통제 시간은 분리한다. 구간 통과 예상 시각이 없으면 출발 시각만으로 통제 영향을 배제하지 않는다.

## 검토한 대안

| 대안 | 이번 범위에 넣지 않는 이유 |
| --- | --- |
| 공지 자동 검색·수집과 변경 감지까지 일괄 구현 | 먼저 한 건의 추출·검수·지도 반영 흐름을 검증하고 후속 확장으로 진행 |
| 추출 결과 즉시 자동 게시 | 원문·통제 구간 대조가 필요한 누락·오추출을 검수할 단계 필요 |
| 자동 우회 경로 생성 | 경로 영향 확인과 별도 기능이며 회피 지원·데이터 검증 전. 후속 검토 |

## 확인할 수용 조건

- 추출값마다 원문 근거를 대조할 수 있고, 누락·충돌 값은 확인 필요로 남긴다.
- 승인 전에는 확정 통제로 게시하지 않고, 수정·승인 후 두 사용자 화면에 같은 정보가 반영된다.
- 자동차·도보의 통제 정보를 구분하고, 지도와 동일한 내용을 텍스트로 확인할 수 있다.
- 목적지 경로 영향은 실제 경로 좌표·통제 구간·시간 조건을 근거로 표시한다. 목적지 핀만으로 기능 완료를 주장하지 않는다.
