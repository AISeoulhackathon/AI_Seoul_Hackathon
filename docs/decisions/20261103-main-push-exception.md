# 이번 기획 변경의 main 직접 푸시 예외

| 필드 | 값 |
| --- | --- |
| 날짜 | 2026-11-03 |
| 결정자 | 사용자 |
| 관련 | 공고·FAQ, [IDEA_03](../ideas/IDEA_03.md), 추가 아이디에이션 메모, 하네스 |

## 결정

사용자의 “아이디어 낸거 main 브랜치 푸시후 해당 하네스에 기록” 요청에 따라 이번 기획·하네스 변경은 main에 직접 반영한다. 기본 브랜치 → PR 정책은 유지하며 이번 요청에만 예외를 적용한다.

## 배경

이번 대화의 미커밋 기획 변경과 브레인스토밍 제안을 저장소에 보존하고 팀이 확인할 수 있도록 반영한다.

## 검토한 대안

| 대안 | 채택하지 않은 이유 |
| --- | --- |
| 별도 브랜치·PR만 생성 | 이번 사용자가 main 푸시를 명시적으로 요청함 |
| 원격 변경 덮어쓰기 | 다른 작업의 아이디어를 보존해야 하므로 정상 병합하며 강제 푸시하지 않음 |

## 영향

원격 최신 main을 확인·병합하고 하네스 검사를 통과시킨 뒤 일반 푸시한다. 전송 결과는 실행 후 work-plan에 기록한다. 아이디어 최종 선정·MVP 승인은 이번 Git 작업에 포함되지 않는다.
